# LOG430 - Projet gabarit front-end
<img src="https://upload.wikimedia.org/wikipedia/commons/2/2a/Ets_quebec_logo.png" width="250">    
ÉTS - LOG430 - Architecture logicielle - Chargé de laboratoire: Gabriel C. Ullmann.

Ce projet est une application front-end pour le Lab 3, développée avec [Vue 3](https://vuejs.org/guide/essentials/application.html) + TypeScript. Le composant `components/HelloWorld.vue` peut facilement être adapté pour fonctionner avec d'autres back-ends. Il suffit de modifier l'endpoint appelé dans le `HelloWorld.vue` et les configurations de proxy dans `vite.config.ts`.

**NOTE** : vous n'êtes pas obligé d'utiliser Vue 3 ou TypeScript pour votre interface utilisateur pendant le cours ; il s'agit uniquement d'une suggestion.
